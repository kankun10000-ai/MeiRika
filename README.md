# 中2理科 単元2 テスト対策アプリ

「生物のからだのつくりとはたらき」（植物・動物・刺激と反応）のテスト対策アプリです。

- 要点のまとめ、4択（101問）、一問一答（163問）、復習、成績（正答率）
- スマホ縦画面向け。記録は端末のブラウザ（localStorage）に保存されます
- ファイルは `index.html` の1つだけです（文字のフォントのみ Google Fonts から読み込み）

## GitHub Pages で公開する手順

1. GitHubで新しいリポジトリを作る（Public）
2. `index.html` と `README.md` をアップロードする（Add file → Upload files）
3. Settings → Pages → Branch を `main` / `(root)` にして Save
4. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で開けます
